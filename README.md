# Syntecxhub_Amazon_Sentiment_Analysis
Project Overview

This project analyzes Amazon customer reviews to understand customer sentiment, identify common feedback patterns, and generate actionable business insights. Using Natural Language Processing (NLP) and Machine Learning techniques, reviews are classified into Positive, Neutral, and Negative sentiments to help businesses improve customer satisfaction and product performance.

Key Features
Data Cleaning and Text Preprocessing
Exploratory Data Analysis (EDA)
Sentiment Analysis using TextBlob
Machine Learning Classification using TF-IDF
Logistic Regression and Naive Bayes Models
Word Frequency and Word Cloud Analysis
Product-Level Performance Analysis
Monthly Sentiment Trend Analysis
Business Insights and Recommendations
